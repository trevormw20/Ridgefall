# Design Specs

These are the source design documents for Ridgefall v0.1. They were provided
across the design sessions and define scope, stats, formulas, and test plans.

The controlling principle: build the SMALLEST playable slice first (3 core jobs,
1 map, defeat-all objective, Classic Mode reactions), prove the core loop is fun,
THEN expand. Do not add races, job unlocks, Active Mode, or the full 27-job roster
until the tiny version proves interesting decisions happen every turn.

## Files
- 01_core_combat_v0.1.md — locked stats, hit/damage formulas, reaction rules
- 02_intro_run_jobs.md — full skill/mechanics spec for all 6 starter jobs + enemies
- 03_round_test_scripts.md — per-round playtest scripts to validate each class

## Balance targets (quick reference)
- Basic attack: 6–10 dmg. Strong skill: 10–16. Big enemy hit: 12–18. Heal: 14–20.
- Battle length: 6–10 rounds. Duelist kills in ~3 hits; Warder 4–5; Lanternist weak.
- Hit chance clamped 20–95. Min damage 1.
